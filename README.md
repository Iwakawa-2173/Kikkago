# Kikkago (菊花語) — эзотерический язык программирования

**Версия 1.0.3**

Kikkago — это эзотерический язык программирования, сочетающий в себе низкоуровневый ассемблер для абстрактного процессора с лентой на 256 ячеек и высокоуровневые конструкции с переменными, массивами, математикой и статистикой. Язык вдохновлён «Хайку-го» (俳句語) и создан как эмулятор странного процессора с элементами стохастики.

## Общее описание

Kikkago позволяет писать код в двух стилях:

- **Низкий стиль** — работа с абстрактным процессором: считыватель и замкнутая лента на 256 ячеек (0/1). Реализует машину Поста и, следовательно, полон по Тьюрингу.
- **Высокий стиль** — работа с переменными (int, float, double, char, bool, string), массивами, математическими и статистическими функциями, файловым вводом-выводом.

Интерпретатор исполняет программу построчно, безусловно цикличен: после последней строки управление переходит на нулевую, пока не встретится `owari` (終わり — конец).

## Архитектура

### Низкий стиль: лента

Лента состоит из **256 ячеек**, каждая хранит `0` или `1`. Лента замкнута:

- После ячейки 256 следует ячейка 0.
- Перед ячейкой 0 расположена ячейка 256.

Считыватель перемещается влево (`<-`) и вправо (`->`), при выходе за границы переходит на противоположный конец.

![Схема языка низкого стиля](https://github.com/user-attachments/assets/placeholder-tape.png)

### Низкий стиль: считыватель

Считыватель — абстрактное вычислительное устройство из трёх логических функций `f(x)`, `g(x)`, `h(x)`. Каждая функция может быть **тавтологией** (`x`) или **отрицанием** (`not(x)`).

Функции применяются последовательно, а затем изменяют друг друга на основе выходных результатов. Режимы работы:

| Режим | Описание |
|-------|----------|
| `00` | Копирование значения из одной ячейки в другую |
| `01` | Сначала данные проходят через функции, затем функции изменяются |
| `10` | Сначала функции изменяются, затем данные проходят через них |
| `11` | Поочерёдное прохождение данных и изменение функций |

Настройки считывателя задаются операторами `f1`, `f2`, `f3`, `conf1`, `conf2`, `prob`, `cycle`.

![Схема считывателя](https://github.com/user-attachments/assets/placeholder-reader.png)

## Синтаксис

```
оператор операнд1 операнд2
```

- Оператор и операнды разделены одним пробелом.
- Строка, начинающаяся с пробела, игнорируется.
- Язык **чувствителен к регистру**.
- Для низкого стиля операнды — адреса ячеек `0..256`. Значение `-1` означает «взятие значения по адресу».
- Для высокого стиля операнды — имена переменных.
- Для `block`, `label`, `do`, `to` — имя блока или метки (без пробелов).

## Темпоралогические аспекты

Помимо чисто вычислительного назначения, Kikkago допускает **темпоралогическую интерпретацию** исполнения программы.

Программу в процессе её исполнения можно рассматривать как **замкнутую временную линию**. Тогда путь по программе (последовательность исполнения строк) описывается **мировой линией в двумерном пространстве-времени**, где:

- **пространственное измерение** — программа (её строки),
- **временное измерение** — порядок исполнения этих строк.

В такой модели возможны **точки схождения и расхождения** мировых линий:

- строки с оператором `bunkiten` — точки **дивергенции и конвергенции** (в зависимости от того, какие последовательности исполнения строк рассматриваются);
- строки с оператором `kyouki` — также точки ветвления, но уже стохастические.

Безусловная цикличность программы усиливает эту аналогию: исполнение замыкается само на себя, образуя петлю времени, а `jikannohajimaru` / `jikannoowari` позволяют явно выделить темпоральный отрезок и измерить его длительность.

Авторы отмечают, что эту теорию можно развивать — вплоть до формализации гипотетической теории стохастических алгоритмов, где процессор Kikkago мог бы служить готовой средой для проверки и формализации её положений.

## Полнота по Тьюрингу

Полнота по Тьюрингу доказывается через реализацию машины Поста:

| Машина Поста | Kikkago |
|--------------|---------|
| `V j` | `hitotsu -1`<br>`goto j` |
| `X j` | `zero -1`<br>`goto j` |
| `← j` | `<-`<br>`goto j` |
| `→ j` | `->`<br>`goto j` |
| `? j1; j2` | `zero 0`<br>`bunkiten -1 0`<br>`goto j1`<br>`goto j2` |
| `!` | `owari` |

Полнота гарантируется даже без использования `henkamono` и вероятностей.

Отдельно отмечается, что полнота по Тьюрингу **самого интерпретатора** (высокий стиль) оставляется читателю в качестве нетрудного упражнения.

## Установка и запуск

1. Распакуйте папку `Kikkago` в удобное место.
2. Откройте консоль (`cmd`).
3. Перейдите в директорию с `kikka.exe`:
   ```
   cd C:\Kikkago
   ```
4. Проверьте работу:
   ```
   kikka
   ```
   Ожидаемый вывод:
   ```
   Usage: kikka <filename>
   IBN-KIKKA-24 - Quine is so easy in this language!
   Version 1.0.3
   ```
5. Запустите программу:
   ```
   kikka programs/ascii.kikka
   ```

### Подсветка синтаксиса

Импортируйте `kikka.xml` в Notepad++ через раздел «Синтаксисы» → «Пользовательский синтаксис».

## Рекомендации

1. Соблюдайте правила синтаксиса.
2. Избегайте вложенных меток, циклов и блочных конструкций.
3. Старайтесь не создавать неоднозначных ситуаций, в которых не уверены.
4. В низком стиле все операнды должны принадлежать списку:
   - `-1`,
   - числа от `0` до `256`.
5. Избегайте `goto`, где это возможно.
6. Проектируйте код на бумаге и проверяйте его в уме перед запуском.
7. В высоком стиле следите за типами; первым операндом всегда должна быть переменная.
8. Не называйте переменные числами.

Эти рекомендации основаны на опыте разработки языка Haikugo (俳句語) и написания на нём программ.
